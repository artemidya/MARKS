# PlotCalc

**PlotCalc** — VBA-проект для CorelDRAW: подготовка кривых, расчёт длины и площади, раскрой, предварительный просмотр и передача заданий на плоттер. Поддерживаются профили устройств, HPGL/DMPL, COM/USB/сетевые подключения и несколько языков интерфейса.

## Основные команды

| Функция | Описание |
|---|---|
| `MainMenu.Plot` | Открывает окно подготовки и вывода задания на плоттер. |
| `MainMenu.Place` | Открывает инструмент раскроя и размещения объектов на листе. |
| `MainMenu.Circulation` | Открывает инструмент создания тиража — дубликатов выделенных объектов. |
| `MainMenu.Perimetr` | Показывает панель расчёта суммарной длины кривых выделения. |
| `MainMenu.Square` | Показывает панель расчёта площади объектов и занимаемой прямоугольной области. |
| `MainMenu.Labirint` | Запускает построение лабиринта по выделенным кривым. |
| `MainMenu.ScaleA3/A4/A5` | Создаёт масштабированную копию выделения под формат A3, A4 или A5 с подписью масштаба. |
| `MainMenu.IntersectionSearch` | Находит пересечения кривых и предлагает отметить найденные точки. |
| `MainMenu.CropBMPsub` | Обрезает растровые изображения по общему контуру с настраиваемым отступом. |
| `MainMenu.TrimCurvesSub` | Обрезает выделенные кривые с учётом заданного расстояния разрыва. |
| `MainMenu.ReGroupShapes` | Соединяет кривые и подпути, сортирует и группирует объекты, при необходимости сокращает число узлов. |
| `MainMenu.RemoveDuplicate` | Удаляет совпадающие линии и сегменты, затем соединяет и замыкает оставшиеся кривые. |
| `MainMenu.ConvertToCurves` | Преобразует выделенные и связанные объекты в кривые с очисткой по настройкам. |
| `MainMenu.settings` | Открывает общие настройки PlotCalc. |

## Ключевые внутренние функции

| Функция | Назначение |
|---|---|
| `CalculateSanP.Start`, `Length`, `Area`, `RectArea` | Обрабатывают выделение и вычисляют длину и площадь кривых. |
| `RaskroyForm.StartNesting` | Запускает алгоритм размещения объектов при раскрое. |
| `PltDocument.Render`, `Sorting` | Отображают задание и оптимизируют порядок обхода кривых. |
| `ConverterPlotCalcCrvToHPGL.Convert`, `ConverterPlotCalcCrvToDMPL.Convert` | Преобразуют внутренние кривые в команды HPGL или DMPL с учётом профиля устройства. |
| `COM.CommOpen`, `CommRead`, `CommWrite`, `CommClose` | Управляют обменом данными через COM-порт. |
| `Profile.Load/Save`, `UserData.Load/Save` | Загружают и сохраняют профили устройств и пользовательские настройки. |
| `localization.SelectLangByCode` | Выбирает язык интерфейса по его коду. |
| `UpdateCenter.UpdatePlotCalc` | Загружает и устанавливает обновление GMS. |

## Структура репозитория

- `Extracted_PlotCalc.gms` — исходный GMS-проект.
- `BAS/` — 1 340 процедур в отдельных файлах.
- `BAS_Grouped/` — те же процедуры в 69 объединённых файлах, сгруппированных по назначению.
- [Описание групп](BAS_Grouped/README.md) и [полный указатель процедур](BAS_Grouped/index.csv).

> BAS-файлы предназначены для просмотра и навигации по извлечённому коду. Полные формы, классы и объявления модулей остаются в исходном GMS.
