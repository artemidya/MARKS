# Логическая группировка PlotCalc BAS

- Исходных отдельных процедур: 1340.
- Тематических групп: 9.
- Объединённых BAS-файлов: 69.
- Код и имена процедур не изменены; порядок внутри исходных модулей сохранён.
- Кодировка BAS-файлов: Windows-1251, переносы строк: CRLF.

Процедуры объединены в пределах исходного модуля, а модули разложены по
тематическим группам. Это необходимо, потому что в разных формах и классах
есть одноимённые процедуры (UserForm_Initialize, Class_Initialize и другие).
Простое объединение всех модулей группы в один BAS создало бы дубликаты имён.
Пары Property Get/Let/Set сохранены в общем файле.

Модули SortingCurve и ColorInfo не содержат процедур, поэтому для них
объединённые файлы не создавались. Объявления вне процедур (глобальные
переменные модуля, Type, Enum, Const и Declare) не входили в исходный комплект
отдельных процедур и здесь не добавлялись.

## Группы

- `01_Application_and_Menu`: 6 BAS, 90 процедур.
- `02_Calculation_and_Nesting_Forms`: 8 BAS, 156 процедур.
- `03_Geometry_and_Curves`: 12 BAS, 130 процедур.
- `04_Plot_Document_and_Export`: 7 BAS, 138 процедур.
- `05_Graphics_Engine`: 7 BAS, 79 процедур.
- `06_Devices_and_Communication`: 14 BAS, 403 процедур.
- `07_Profiles_and_Settings`: 5 BAS, 210 процедур.
- `08_Common_Utilities`: 7 BAS, 112 процедур.
- `09_Licensing_and_Updates`: 3 BAS, 22 процедур.

`index.csv` содержит связь каждой процедуры с объединённым файлом, исходным
модулем, номерами строк и первоначальным отдельным BAS-файлом.
